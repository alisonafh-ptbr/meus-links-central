# 🔗 Meus Links Úteis (PWA)

Um aplicativo web leve, moderno e responsivo para gerenciar, organizar e acessar seus links favoritos rapidamente, com suporte a categorias, backup em JSON e funcionamento offline como um PWA (Progressive Web App).

## ✨ Funcionalidades

- **Organização por Pastas/Categorias:** Agrupe seus links por temas.
- **Reordenação por Drag and Drop:** Arraste e solte os links facilmente para reorganizá-los.
- **Exclusão Rápida:** Arraste um link para o ícone de lixeira flutuante para removê-lo.
- **Backup Completo:** Exporte e importe todos os seus dados e categorias facilmente via arquivo JSON (compatível com Android e iOS).
- **Modo Escuro Automático:** Adapta-se ao tema do seu sistema operacional.
- **Instalável (PWA):** Instale direto no celular (Android/iOS) ou no computador como um aplicativo nativo.

## 🚀 Como Acessar / Instalar

Você pode acessar a versão online publicada pelo GitHub Pages e instalá-la no seu dispositivo:

1. Abra o link do projeto no navegador do seu celular ou computador.
2. No **Android (Chrome)**: Toque nos três pontos no canto superior direito e selecione **Instalar aplicativo** ou **Adicionar à tela inicial**.
3. No **iPhone (Safari)**: Toque no botão de Compartilhar e selecione **Adicionar à Tela de Início**.

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3** (com variáveis para Design Responsivo e Dark Mode)
- **JavaScript Vanilla** (sem dependências externas pesadas)
- **LocalStorage API** (para persistência de dados local)
- **Web App Manifest** (para suporte a PWA)
